# Comparator-driven review procedure

Use this only when a supplied brief/reference and reproducible rendered
evidence provide a comparator. Make these passes in order: required content and
primary action; source order and landmarks; macro geometry and reflow;
hierarchy, type, measure, and rhythm; media crop and surfaces; then interaction,
focus, and motion. Decoration is last: it cannot make an absent action,
incorrect order, or overflowed required content merely cosmetic.

For each pass, record expected intent, observed condition, viewport/state,
evidence pointer, severity/confidence, likely owner, and the smallest next
observation. Record missing evidence as uncertainty rather than inventing a
mobile target. A polished desktop image with an absent mobile action, wrong
reading order, and long-heading overflow therefore has three primary findings;
a border mismatch is minor.

This is an original, read-only evidence procedure from CV-07/PS-10/PS-11 and
HTML/WAI source classes. It is not an acceptance, accessibility-certification,
or copied visual recipe.
